# 食刻搜 · 前端数据包

菜谱数据抓自美食天下（meishichina.com），厨具广告位数据抓自当当。  
**全部 UTF-8 带 BOM，Excel 可直接打开；前端 parse CSV 时记得去掉 BOM。**

## 三、广告位怎么匹配

`投放标签` 是菜谱和厨具之间的桥梁：

```js
// 菜谱特色 "咸鲜 · 炒" → 取工艺词
const craft = recipe.特色.split(" · ")[1];

const ad = kitchenware.find(k =>
  k.投放标签.includes(craft) || k.投放标签.includes(recipe.分类)
) || kitchenware.find(k => k.投放标签.includes("通用"));
```

| 投放标签            | 对应厨具          | 触发的菜谱            |
| --------------- | ------------- | ---------------- |
| `炒\|煎 · 热菜`     | 炒锅、锅铲         | 特色含「炒」「煎」，或分类=热菜 |
| `炖\|煮\|煲 · 汤羹`  | 炖锅、砂锅、不锈钢锅    | 分类=汤羹，或特色含「炖煮煲」  |
| `蒸 · 主食/小吃`     | 蒸锅            | 特色含「蒸」           |
| `炸\|烤 · 烘焙`     | 空气炸锅、烘焙工具     | 分类=烘焙，或特色含「炸烤」   |
| `搅打\|榨汁 · 自制食材` | 料理机           | 分类=自制食材          |
| `通用 · 全站`       | 餐具、砧板、刀具、厨房用具 | 兜底               |

## 四、四个注意点

**1. BOM**  
CSV 是 UTF-8 带 BOM（让 Excel 打开不乱码）。用 `fetch` + `text()` 解析时，第一列名会变成 `\uFEFF菜谱ID`，记得先去掉：

```js
const text = (await fetch('list.csv').then(r => r.text())).replace(/^\uFEFF/, '');
```

**2. 图片有防盗链，别禁用 Referer**  
美食天下的图必须带 Referer 才返回 200，**不带 Referer 会 403**。浏览器 `<img src>` 默认会带当前页面地址，所以正常显示；但如果给 img 加了 `referrerpolicy="no-referrer"`，图片会全部裂开。

```html

<img src="https://i3r.meishitx.com/atta/recipe/...jpg">

<img src="..." referrerpolicy="no-referrer">
```

厨具图（当当 CDN）没有这个限制。

**3. 线上务必开 gzip**  
`list.csv` 原始 3.99 MB，gzip 后只有 0.77 MB。Nginx 加一行 `gzip_types text/csv application/json;` 即可。  
`detail` 是按需加载的，首屏不用管。

**4. 不要在首屏加载 `detail`**  
详情页再请求对应分片，单片约 0.7 MB（gzip）。整个包 30 MB 是一次性下不动的。
